## ✨ Features & Highlights

- **Hardware-Accelerated Frame-by-Frame Scroll Video**: Apple-grade smooth video scrubber powered by in-memory Blob buffering, non-blocking seek queues, and compositor-synchronized `requestVideoFrameCallback`.
- **Dynamic Work-Scoped Timeline**: Pinned glassmorphic side card that synchronizes in real time with video frames across career stages (bKash ➔ Alice Labs / Revora ➔ Mayalogy & BRAC University CSE).
- **Interactive System Topology Simulator**: Animated SVG circuit energy flows and glowing particle pipelines illustrating FinTech, IDS, G2P EFT, bKash Forest, and Revora AI architecture.
- **Kinetic Pop-Card Event Dispatcher**: Live simulator spawning 3D floating telemetry pop cards with spring physics from anywhere across the screen.
- **3D Magnetic Tilt Physics**: Perspective card hover tracking with specular crimson glare reflections.
- **Obsidian & Crimson Design System**: Ultra-clean dark theme (`#040406`) with vibrant shades of red and zero white-screen FOUC flash.

## 🛠️ Technology Stack

- **Core**: Vanilla HTML5, ESNext JavaScript, Vanilla CSS3 (Custom Design System Tokens)
- **Animation Engine**: [GreenSock Animation Platform (GSAP 3)](https://greensock.com/gsap/) & [ScrollTrigger](https://greensock.com/scrolltrigger/)
- **Bundler & Dev Server**: [Vite 7](https://vitejs.dev/)

## 🚀 Quick Start & Development

### 1. Install Dependencies
```bash
npm install
# or
pnpm install
# or
yarn install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
Generates an optimized production bundle in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```

## 🌐 Production Deployment

### Deploy to Vercel
```bash
npx vercel
```
*Build Command:* `npm run build`  
*Output Directory:* `dist`

### Deploy to Netlify
```bash
npx netlify deploy --prod
```
*Publish Directory:* `dist`
