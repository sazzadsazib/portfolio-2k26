bKash Forest: Sustainability Gamification Platform

bKash Limited · Led by Md. Sazzadul Islam (Sazib)

Problem Statement

How to transform millions of routine financial transactions into verified real-world ecological action without introducing any latency or friction to core payment flows?

Architectural Solution

  • Decoupled Event Stream: Transactions emit lightweight Kafka events. The bKash Forest microservice processes reward loops asynchronously without adding latency to payment paths.
  • Gamification Ledger: A specialized double-entry point system that credits digital tree seeds to user wallets upon eligible financial actions (DPS savings, utility payments, contactless QR).
  • Verified Tree Plantation Sync: Real-time integration with NGO tree plantation partners with GIS geo-tagging, satellite verification, and CO₂ offset telemetry.
